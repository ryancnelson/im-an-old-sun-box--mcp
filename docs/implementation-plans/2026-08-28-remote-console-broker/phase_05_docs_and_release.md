# Phase 5: documentation and release

## Tasks

1. Update `SPEC.md` with the broker, policy, RPC, authentication, and console
   tool contracts.
2. Update `README.md`, `TODO.md`, `docs/OPERATIONS.md`, and
   `examples/config.toml`.
3. Run the full test suite and build the wheel.
4. Review the branch diff for secrets, dated host assumptions, unbounded I/O,
   and accidental changes.
5. Commit implementation milestones and push the branch.

## Done when

The repository documents the deployed behavior, all tests pass, the wheel
builds, and no credentials or private values are committed.
